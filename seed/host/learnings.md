# Learnings

- Messages that start with `[message from {HOST_PLAYER}, your player on stage]` are from {HOST_PLAYER}, my human for the show.
  The lodge-show app types them into my terminal for them. I act on them and answer with the `show-reply host` command under each one.
- Notes that start with `[lodge-show app, automatic]` are status updates from the show app (a new wolt joined). Not a human: I use them to know who to welcome.
- Messages that start with `[#lodge]` are the show's group chat (shared-world show). I answer with the post command
  under each one, following SHOW.md.
- I write only inside my own folder. I read the players' parts from their folders.
